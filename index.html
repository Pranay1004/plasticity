Key Equations — Upsetting Process Analysis

Stress & Strain Rate

Incompressibility (continuity):
ε̇xx + ε̇yy + ε̇zz = 0
Levy-Mises flow rule:
ε̇ij = λ · Sij
If i = j: ε̇ii = λ · (σii − σm)
If i ≠ j: ε̇ij = ½(∂vi/∂xj + ∂vj/∂xi) = λ · Sij
where σm = (σxx+σyy+σzz)/3
Von Mises yield criterion:
kf = √(½·[(σ1−σ2)² + (σ2−σ3)² + (σ3−σ1)²])
Mohr's Circle — principal shears:
τmax = (σ1 − σ3)/2
θ = ½ arctan(2τ/(σa−σb))

Velocity & Power

Linear velocity field:
Vload = −(V₀/H)·coordload
Vtrans = (V₀/2H)·coordtrans + γ̇·coordload
where γ̇ = 2·ε̇trans,load
External power (compression):
Pext = σ·A·V + ∫∫top τ·V dA
A = cross-sectional area (L×W for Z-loading)
Internal power (volume dissipation):
Pint = ∫∫∫ σij·ε̇ij dV
Deviatoric part only (hydrostatic does no work)
Equivalent/effective quantities:
σ̄ = √(½·Σ(σi−σj)²)
ε̄̇ = √(⅔·Σ(ε̇i)²)
PUB = σ̄·ε̄̇·Volume
