ITERATION 3: AXIS-AGNOSTIC GENERALIZATION (Z→X,Y,Z SUPPORT)
================================================================================

Changes Made:

A. Core Helper Functions Added
   - axisIndex(axis): Returns 0/1/2 for X/Y/Z
   - getBounds(L, W, H, loadDir, bcType): Computes axis bounds
     * For load axis: [0, H] if fixed, [-H/2, H/2] if free
     * For transverse axes: [-size/2, size/2]
   - symmetrizeTensor(T): Averages off-diagonal pairs for asymmetric input
   - pointInBounds(point, bounds): Validates [x,y,z] against workpiece limits
   - representativeCoords(bounds, loadDir): Generates 3 default probe points

B. Stress Tensor Handling (analyze function)
   - Input stored as Sraw (raw user input)
   - Calculation uses S (symmetrized tensor)
   - Tensor mapping now axis-aware via dirIdx
   - Simple shear input mode adapts to load direction:
     * Z-loading: τ_zy, τ_zx, τ_xy → [2][1], [2][0], [0][1]
     * Y-loading: τ_zy, τ_zx, τ_xy → [1][2], [1][0], [0][2]
     * X-loading: τ_zy, τ_zx, τ_xy → [0][2], [0][1], [1][2]

C. FBD Function (drawFBD) Generalization
   - Now accepts bounds parameter
   - Corner points calculated from bounds instead of hardcoded 0→L, 0→W, 0→H
   - Support BC visualization adapts to load direction
   - Shear arrows render for correct stress components based on axis
   - FBD renders for all three axes (Z, Y, X)

D. Velocity Field Canvas (drawVelocityField) Generalization
   - Accepts bounds parameter
   - Selects cross-section dynamically based on loadDir:
     * Z-loading: X-Z cross-section (Y=0)
     * Y-loading: X-Y cross-section (Z=0)
     * X-loading: Y-X cross-section (Z=0)
   - Axis labels and grid plotting adapt to selected section
   - Velocity vectors computed axis-aware via coordValue() helper
   - Canvas title updates to show correct axes

E. Velocity Field Functions Refactored
   - Vx, Vy, Vz now compute shear terms from stress tensor based on loadDir
   - Z-loading: Vx includes τ_zx, Vy includes τ_zy
   - Y-loading: Vx includes τ_yx, Vz includes τ_yz
   - X-loading: Vy includes τ_xy, Vz includes τ_xz
   - All functions accept (x, y, z) and adapt to load direction

F. Probe Coordinate System
   - Added input fields: #probeX, #probeY, #probeZ
   - Default values: 0, 0, 0
   - Real-time validation via pointInBounds()
   - Message updates: "Probe point (x, y, z) is inside the current bounds."
   - Rejects points outside workpiece and shows bounds

G. Power Integration Fixes
   - Variable name collision resolved:
     * Renamed: xLow→faceXLow, xHigh→faceXHigh, yLow→faceYLow, yHigh→faceYHigh
   - Loaded face area now axis-aware:
     * Z-loading: A_top = L*W
     * Y-loading: A_top = L*H
     * X-loading: A_top = W*H
   - Lateral power integration (computeLateralPower) now handles all axes:
     * Z-loading: lateral face at y=W/2
     * Y-loading: lateral face at x=L/2
     * X-loading: lateral face at y=W/2

H. renderResults Function Updates
   - Split stress tensor display: shows both raw (user input) and symmetric (calculated)
   - Explanation: "Raw input is shown above, calculation uses averaged off-diagonal pairs"
   - All 12 result panels (a-m) now render with proper HTML subscript formatting
   - Deviatoric tensor display with all subscripted components

ITERATION 5: POWER BALANCE FIX & EMOJI REMOVAL
================================================================================

Date: May 1, 2026 (Session 2)
Status: Power balance corrected, emojis removed, test cases validated

Changes Made:

A. Internal Power Calculation Fix
   - PREVIOUS ERROR: P_int_density = Σ(S[i][j] * eSR[i][j]) (used total stress)
   - FIX: P_int_density = Σ(devTensor[i][j] * eSR[i][j]) (use deviatoric stress)
   - devTensor = S[i][j] - (i===j ? sm : 0) where sm = I1/3
   - Result: P_int now matches P_ext when velocity field is compatible

B. Power Cards Split (i, j, k separated)
   - PREVIOUS: Combined card showing P_ext, P_int, P_principal
   - FIX: Three separate cards:
     * (i) External Power: P_compression + P_shear(top) = P_ext
     * (j) Internal Power: P_int = devTensor:ε̇ × Volume
     * (k) Principal Power: P_via principal × principal strain rate
   - Each card shows breakdown and Δ = P_ext - P_int

C. Hydrostatic Tensor Display Added
   - Section (c) now shows:
     * Principal Stresses: σ₁, σ₂, σ₃
     * Hydrostatic σ_m = I₁/3
     * Hydrostatic Tensor [σ_H] = [sm 0 0; 0 sm 0; 0 0 sm]
     * Deviatoric Tensor [S] = [σ] - [σ_H]

D. Velocity Field Equations Corrected
   - User specification implemented:
     * V_load = -V0/H_load * coord_load
     * V_trans1 = +V0/(2H_load) * coord_trans1
     * V_trans2 = +V0/(2H_load) * coord_trans2 + (γ̇_shear) * coord_load
   - Where γ̇_shear = 2 * eSR[trans][load] (engineering shear strain rate)
   - Z-loading example (H=50, V=2, τ_zy=5):
     Vx = 0.02·x
     Vy = 0.02·y + 0.06·z
     Vz = -0.04·z

E. Representative Coordinates Fixed
   - PREVIOUS: Points outside workpiece bounds (e.g., x=25 when X: 0-20)
   - FIX: Use 80% of bounds to stay within range
   - Function now returns [loadMid, t1Mid, t2Mid], [loadBound, t1Mid, t2Mid], [loadMid, t1Bound, t2Bound]
